# SmartTherma – Intelligent Thermal Breast Health Assistant

## Overview
SmartTherma is a MATLAB-based intelligent diagnostic assistant designed for early breast cancer risk assessment using thermal imaging and machine learning. The system analyzes breast thermography images, extracts important thermal features, and predicts tumor risk using trained classification models.

The application includes an interactive GUI that enables healthcare professionals to upload thermal images, perform real-time analysis, and visualize suspicious tumor regions efficiently.

---

## Features
- Thermal breast image analysis using image processing
- Early-stage tumor risk prediction using Machine Learning
- Zone-wise abnormality detection
- Feature extraction (Mean, Max Intensity, Texture Analysis)
- Real-time MATLAB GUI for easy interaction
- Heatmap visualization for suspicious regions
- Patient symptom input support
- Risk score prediction with classification output
- Support for public thermal imaging datasets
